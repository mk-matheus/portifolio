# Matheus Kauã — Portfólio

Portfólio pessoal de **Matheus Kauã**, desenvolvedor fullstack júnior em Recife/PE.

O projeto apresenta minha experiência, formação, principais habilidades e cases construídos com Java/Spring Boot, NestJS, React e Next.js.

## Stack

- Next.js 15 e React 19
- JavaScript, TypeScript e Tailwind CSS
- GSAP para animações e interações
- Lucide React para ícones
- Deploy recomendado: Vercel

## Executar localmente

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.

Para validar a versão de produção:

```bash
npm run build
npm run start
```

## Estrutura

```text
app/          páginas, metadata, sitemap e rotas de projetos
components/   navegação, seções, animações e componentes de interface
data/         perfil, habilidades, experiências e projetos
public/       currículo e imagens do portfólio
```
